# Ultimate Truck Empire — Unity Android

This directory is the production Unity game. The existing web app remains outside this directory as a prototype/reference.

## Unity setup

Recommended Unity LTS version: Unity 6 LTS or the current supported Unity LTS available when the project is opened.

Required modules:
- Android Build Support
- Android SDK & NDK Tools
- OpenJDK

## First playable milestone
- Boot into a 3D driving scene
- Spawn a truck
- Third-person chase camera
- Mobile throttle/brake/steering hooks
- Basic road and depot blockout
- Speed/fuel HUD
- Clean separation between driving and tycoon systems

## Production art direction
Use authored 3D assets rather than procedural boxes for final visuals. Target a premium mobile trucking/tycoon look with PBR materials, optimized lighting, LODs, baked/static lighting where appropriate, and controlled post-processing.
