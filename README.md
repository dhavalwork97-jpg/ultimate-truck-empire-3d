# Ultimate Truck Empire 3D

A browser-based 3D trucking tycoon built with React, Vite and Three.js.

## Current playable build

- Real WebGL 3D world with a drivable tractor-trailer
- Third-person follow camera
- Procedural roads, city blocks, trees, depot and parked fleet trucks
- Physical destination zones rendered in the 3D world
- Contract dispatch system with cargo, route, payout and XP
- Drive into the glowing destination ring to complete a delivery automatically
- Live speed and fuel telemetry
- Fuel consumption while driving
- Engine, gearbox, tire and fuel-tank upgrades
- Fleet truck purchasing, driver hiring and depot expansion
- Level / XP progression
- Local save/load using browser localStorage
- Responsive command-center HUD

## Controls

- **W / Arrow Up:** accelerate
- **S / Arrow Down:** brake / reverse
- **A / Arrow Left:** steer left
- **D / Arrow Right:** steer right
- **Space:** reserved for expanded braking controls

## Run locally

```bash
npm install
npm run dev
```

Then open the Vite development URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```
