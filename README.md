# Ultimate Truck Empire 3D

A browser-based 3D trucking tycoon game built with Three.js/React.

## Vision

Build a trucking company from a tiny depot into a large logistics empire. Drive trucks, complete contracts, buy and upgrade vehicles, hire drivers, expand the depot, and grow the fleet.

## Development

The repository is being bootstrapped as a real WebGL 3D game. The first milestone is a playable vertical slice with a 3D depot, drivable truck, contracts, economy, garage, progression, and local save/load.
