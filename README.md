# Ultimate Truck Empire

Unity 6 base game for **ULTIMATE TRUCK EMPIRE** — DRIVE THE TRUCK. BUILD THE COMPANY. CREATE THE EMPIRE.

## Unity preview

1. Open the `UnityProject` folder in Unity **6000.0.65f1**.
2. Open `Assets/Scenes/World_Gujarat.unity`.
3. Press **Play**. `RuntimeBootstrap` creates the playable world automatically.
4. If the scene is not visible in the Project window, use `Ultimate Truck Empire > Build Phase 1 World` from the Unity Editor menu.

## Current base gameplay

- 3D player truck with wheel colliders, suspension, braking and steering
- Dry-van trailer foundation
- Pickup and destination delivery triggers
- Contract market with generated freight jobs
- Driver hiring and skill progression
- Fleet ownership and capacity
- Automated driver/truck dispatch
- Clickable contract → driver → truck dispatch center
- Company, reputation, HQ and branch foundation
- Finance, revenue, expenses, debt and loans
- JSON save/load of company, drivers, fleet and finance
- Truck dealership with six fictional trucks and specifications
- Day/night cycle and weather states
- Traffic spawning foundation
- City/map data foundation
- Starter mission/progression foundation

## Controls

- **WASD / Arrow keys:** drive
- **Space:** brake
- **I:** engine
- **L:** headlights
- **Q / R:** indicators
- **F1–F6:** management views
- **F7:** cycle weather
- **D:** truck dealership

The project uses only fictional manufacturers/assets in the base systems; no Truck Simulator: Ultimate proprietary assets are included.
