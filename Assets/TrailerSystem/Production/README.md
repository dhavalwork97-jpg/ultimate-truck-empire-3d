# Production Trailer Asset Intake

Controlled intake boundary for production trailer art.

Only assets with documented commercial redistribution rights may enter production. Retain license or permission evidence when required. Do not copy meshes or textures from reference packs without explicit redistribution rights.

Imported models must use the Trailer System import pipeline. Production prefabs must pass catalog, prefab-contract, physics-contract, and launch-set validation. Generated sockets and colliders are integration scaffolding only and must be replaced with authored production data.
