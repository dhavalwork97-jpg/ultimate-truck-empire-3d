# Trailer Production Intake Checklist

For each launch trailer:

- [ ] Source/vendor recorded
- [ ] Commercial redistribution rights confirmed
- [ ] Attribution requirements recorded
- [ ] Meshes/textures are original or licensed for redistribution
- [ ] Model imported through the Trailer System pipeline
- [ ] Authored kingpin and wheel sockets present
- [ ] Authored cargo socket present where applicable
- [ ] Production non-trigger collider present
- [ ] LODGroup and intended LOD count present
- [ ] Mobile geometry/material/texture budgets pass
- [ ] TrailerDefinition references production prefab
- [ ] Launch-set validator passes
